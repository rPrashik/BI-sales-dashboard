**Power BI Sales Dashboard :**

This repository contains the `.pbix` file for a dynamic and interactive sales dashboard built in Microsoft Power BI. It analyzes the Superstore sales dataset to provide key insights into business performance across different regions and product categories.

**✨ Key Features & Visuals :**
The dashboard provides a multi-perspective view of the sales data, focusing on:
- **Executive KPIs:** At-a-glance cards for Total Sales, Profit Margin, Total Orders, and Shipping Costs.
- **Temporal Analysis:** Line charts showing sales and profit trends over months, quarters, and years.
- **Geographical Insights:** A map visualization displaying sales performance by state and region.
- **Product Analysis:** Bar charts that break down sales by product Category and Sub-Category.
- **Customer Segmentation:** Analysis of sales distribution across different customer segments.
- **Full Interactivity:** The entire report is interactive, using slicers to filter data dynamically by date, region, and category.

**🛠️ Tools Used :**
- **Microsoft Power BI Desktop:** Used for data modeling, creating measures (DAX), and building all visualizations.
- **Microsoft Excel:** Used for initial data inspection.

**🚀 How to View and Use :**
1.  Download the `Sales Dashboard.pbix` file from this repository.
2.  Open the file using **Power BI Desktop**.
3.  Interact with the slicers and click on visuals to explore the data insights.
