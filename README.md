**🚀 Purpose :**
The goal of this dashboard is to analyze sales performance, identify trends, and visualize key performance indicators (KPIs) such as total sales, profit, and order quantity.

**🛠️ Tools Used :**
* Microsoft Power BI for Data Cleaning, Feature Engineering, Exploratory Data Analysis, Data Visualization and Report building

**📁 Dataset :**
The project uses the `SuperStore_Sales_Dataset.csv` and `.xlsx` files, which contain all the data for a superstore including (order id, order date, ship date, ship mode, customer id, customer name, segment, country, city, state, quantity,profit, payment mode, sales, etc)
